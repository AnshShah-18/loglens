# Docs Assets

This folder stores screenshots and demo media used by the root README.

## Recording A Demo GIF
- Recommended tools on macOS:
  - QuickTime Screen Recording
  - Kap
- Keep the demo short (20-30 seconds).
- Suggested flow:
  1. Upload `samples/demo.log`
  2. Upload `samples/demo_new.log`
  3. Show the `NEW` badge appearing on the second upload
